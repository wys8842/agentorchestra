# Memory v1.1 — 衰减机制 + 多命名空间

- Status: Approved
- Date: 2026-09-03
- 关联：v1 设计 `2026-09-03-memory-system-design.md`

## 1. 背景与目标

v1 已交付跨会话持久记忆（含 MemoryEntry、三种后端、关键词+向量混合检索、MemoryManager、MemorySave/Recall 工具、自动注入前缀）。

v1 已知限制：
- 所有记忆共享一个空间，多用户/多 Agent 场景会互相污染
- 缺乏衰减机制，老旧低价值记忆长期占据召回

v1.1 目标：补两个能力，**默认行为不变（向后兼容）**，需手动开启。

## 2. 范围

| 包含（v1.1） | 不包含（未来） |
|--------------|---------------|
| `MemoryEntry.namespace` 字段（默认 "default"） | 多 namespace 继承（如 user:alice → user:alice:finance） |
| 三种后端支持 namespace 过滤 + SQLite 迁移 | 按 namespace 加密隔离 |
| `HybridRetriever.recall` 支持衰减打分（Ebbinghaus） | 主动遗忘任务（定时清理） |
| `MemorySave/RecallTool` 加 `namespace` 参数 | namespace 级权限模型 |
| `MemoryManager` 全部 API 加 namespace 参数 | 跨 namespace 检索（"全局") |
| Agent 自动回忆用 `config.memory_namespace` | 多个 namespace 合并召回 |
| Config 加 5 个新字段（默认关闭/默认 "default"） | |

## 3. 数据模型

```python
@dataclass
class MemoryEntry:
    id: str
    type: MemoryType
    content: str
    tags: List[str]
    importance: float
    embedding: Optional[List[float]] = None
    source_session: str = ""
    source_agent: str = ""
    namespace: str = "default"     # ← 新增（默认值保持向后兼容）
    created_at: str
    updated_at: str
    access_count: int = 0
    last_accessed_at: Optional[str] = None
```

`to_dict()` / `from_dict()` 序列化 `namespace`，缺失时默认 "default"。

`accessed()` 行为**不变**（只更 access_count + last_accessed_at，不动 updated_at）。
`recall` 命中后由 `MemoryManager.recall` 主动调 `entry.touch()` 重置 `updated_at`（强化）。

## 4. 衰减公式

```
Δt_days = (now - updated_at) / 86400                # 秒 → 天
τ_days  = lerp(τ_min_days, τ_max_days, importance)  # importance 0→τ_min, 1→τ_max
decay   = 2 ^ (-Δt_days / τ_days)                    # Ebbinghaus 遗忘曲线
effective_score = fused_score × decay × importance
```

- 默认 `memory_decay_enabled=False` → `effective_score = fused_score`（与 v1 一致）
- `τ_min_days=7.0`（importance=0 的半衰期）
- `τ_max_days=180.0`（importance=1 的半衰期）

## 5. 存储层

### 5.1 `BaseMemoryBackend` 接口

```python
@abstractmethod
def iter_all(self, namespace: str = "default") -> Iterable[MemoryEntry]: ...

# 其余 upsert/get/delete/all 不变
```

`all(namespace)` 保留向后兼容：默认传 "default"。

### 5.2 `SqliteBackend` 迁移

启动时用 `PRAGMA table_info(memories)` 检测 `namespace` 列是否存在，缺则：

```sql
ALTER TABLE memories ADD COLUMN namespace TEXT NOT NULL DEFAULT 'default';
CREATE INDEX IF NOT EXISTS idx_memories_namespace ON memories(namespace);
```

后续 `INSERT/REPLACE` 语句包含 `namespace` 列；`iter_all(ns)` 用 `WHERE namespace = ? ORDER BY updated_at DESC`。

### 5.3 `JsonlBackend` / `InMemoryBackend`

内存字典保持按 id 索引，`iter_all(ns)` 过滤即可。无需 schema 变更。

## 6. 检索层

`HybridRetriever.recall` 新签名：

```python
def recall(
    self,
    query: str,
    top_k: int = 5,
    types: Optional[List[MemoryType]] = None,
    namespace: str = "default",
    decay_enabled: bool = False,
    tau_min_days: float = 7.0,
    tau_max_days: float = 180.0,
) -> List[MemoryEntry]:
```

新逻辑：

1. 关键词预筛（不变）
2. **namespace 过滤**：从预筛结果中剔除 namespace 不匹配的条目
3. 类型过滤（不变）
4. 向量精排（不变）
5. 融合归一化（不变）
6. **衰减打分**（仅当 `decay_enabled=True`）：`score × decay × importance`
7. 取 top_k
8. **强化**：每条命中 `entry.touch()` 重置 updated_at

## 7. 管理器

```python
class MemoryManager:
    def remember(self, content, type=..., tags=None, importance=0.5,
                 source_session="", source_agent="", namespace=None) -> str:
        ns = namespace or self.default_namespace
        ...

    def recall(self, query, top_k=5, types=None, namespace=None) -> List[MemoryEntry]:
        ns = namespace or self.default_namespace
        return self.retriever.recall(
            query, top_k=top_k, types=types,
            namespace=ns,
            decay_enabled=self._decay_enabled,
            tau_min_days=self._tau_min_days,
            tau_max_days=self._tau_max_days,
        )

    def list(self, types=None, limit=50, namespace=None) -> List[MemoryEntry]:
        ns = namespace or self.default_namespace
        ...
```

`from_config` 读取：
```python
default_namespace = getattr(config, "memory_namespace", "default")
decay_enabled = bool(getattr(config, "memory_decay_enabled", False))
tau_min = float(getattr(config, "memory_decay_tau_min_days", 7.0))
tau_max = float(getattr(config, "memory_decay_tau_max_days", 180.0))
```

## 11. 错误处理

| 场景 | 行为 |
|------|------|
| SQLite `ALTER TABLE` 失败 | log error + warning，继续运行（默认 namespace仍生效） |
| `tau_min >= tau_max` | log warning，使用默认 7.0 / 180.0 |
| `parse(updated_at_iso)` 异常 | 该条目的 decay视为 1.0 |
| namespace 为 None 或空字符串 | 视为 "default" |
| namespace 不存在的过滤 | 返回空列表，正常 |

原则：**任何 namespace/衰减失败都不得让 Agent 主流程崩溃**。
