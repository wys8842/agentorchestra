# tools - 工具系统

Agent 的能力扩展系统：Tool 定义、注册表、统一执行、内置工具、MCP/技能集成。

## 模块组成

| 文件 | 职责 |
|------|------|
| `base.py` | `Tool` 基类、`ToolParameter`、`tool_action` 装饰器、`AutoGeneratedTool` |
| `registry.py` | `ToolRegistry`：注册/查找/执行工具，熔断器 |
| `response.py` | `ToolResponse` / `ToolStatus`：统一返回协议 |
| `errors.py` | `ToolErrorCode`：标准化错误码 |
| `tool_filter.py` | `ToolFilter`：子代理工具权限控制 |
| `circuit_breaker.py` | 熔断器（连续失败保护） |
| `builtin/` | 内置工具集合 |

## 定义 Tool 的 4 种方式

### 1. 自定义 Tool 子类（推荐）

```python
from agentorchestra.tools.base import Tool, ToolParameter
from agentorchestra.tools.response import ToolResponse

class WeatherTool(Tool):
    def __init__(self):
        super().__init__(name="Weather", description="查询天气", expandable=False)

    def get_parameters(self):
        return [
            ToolParameter(name="city", type="string",
                description="城市名", required=True)
        ]

    def run(self, parameters) -> ToolResponse:
        city = parameters.get("city")
        return ToolResponse.success(text=f"{city} 晴 25°C")

registry.register_tool(WeatherTool())
```

### 2. register_function（最简）

```python
def get_weather(city: str) -> str:
    """查询天气"""
    return f"{city} 晴"
registry.register_function(get_weather)
```

### 3. AutoGeneratedTool（签名自动解析）

```python
from agentorchestra.tools.base import AutoGeneratedTool

def add(a: int, b: int) -> int:
    """两数相加"""
    return a + b
registry.register_tool(AutoGeneratedTool(parent=None, method=add))
```

### 4. @tool_action（一个类=多个工具）

```python
from agentorchestra.tools.base import Tool, tool_action

class MemoryTool(Tool):
    def __init__(self):
        super().__init__(name="Memory", description="记忆管理", expandable=True)

    @tool_action("memory_add", "添加记忆")
    def _add(self, content: str) -> str:
        return f"已记忆: {content}"
```

## 工具执行

```python
# Agent 内部（同步）
result = agent._execute_tool_call("Weather", {"city": "北京"})

# Agent 内部（异步）
response = await tool.arun_with_timing(arguments)

# 外部直接调用
response = registry.execute_tool("Weather", '{"city": "北京"}')
```

**ToolResponse 协议**：
```python
ToolResponse.success(text="...", data={...})
ToolResponse.partial(text="部分成功...")
ToolResponse.error(code="NOT_FOUND", message="...")
```

## 内置工具

| 工具 | 类 | 自动注册条件 |
|------|-----|-------------|
| Read/Write/Edit/MultiEdit | `file_tools.py` | 显式注册 |
| Calculator | `calculator.py` | 显式注册 |
| Task（子代理） | `task_tool.py` | `subagent_enabled` |
| Skill（技能） | `skill_tool.py` | `skills_auto_register` |
| TodoWrite | `todowrite_tool.py` | `todowrite_enabled` |
| DevLog | `devlog_tool.py` | `devlog_enabled` |
| MCP 工具 | `mcp_tool.py` | `mcp_enabled` |

## MCP 集成

```json
{
  "mcpServers": {
    "filesystem": {"command": "npx", "args": ["-y", "@modelcontextprotocol/server-filesystem"]}
  }
}
```

`Config(mcp_enabled=True)` 自动连接 MCP server 并封装为 Tool。

## 工具过滤（子代理权限）

```python
from agentorchestra.tools.tool_filter import ReadOnlyFilter, FullAccessFilter, CustomFilter

subagent.run_as_subagent(task, tool_filter=ReadOnlyFilter())
```
