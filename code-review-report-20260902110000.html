2. Consistency Patterns

All agent types follow the same core patterns:

  • Inheritance: All extend the Agent base class from core/agent.py
  • Message building: All implement _build_messages(input_text) producing system + history + user messages
  • Tool schemas: All use _build_tool_schemas() from ToolRegistry, with optional built-in tools
  • Tool execution: All use serialize_tool_calls(), parse_tool_arguments(), and _execute_tool_call()
  • Timing: All use duration_seconds() from core/utils.py
  • Trace logging: All use self.trace_logger.log_event() for session_start/model_output/tool_call/tool_result/session_end
  • Session finalization: All use unified _finalize_session()
  • Deprecated APIs: add_tool and remove_tool have deprecation warnings, directing to register_tool/unregister_tool
  • Stream events: arun_stream() yields StreamEvent types from core/streaming.py

3. New: LoopAgent

The LoopAgent was added as a 5th agent type, providing generic loop-based Function Calling execution:

  • Calls LLM with tool_choice="auto" in each iteration
  • If tool calls returned: executes them and feeds results back to LLM
  • If no tool calls: returns LLM's final answer
  • Terminates when: LLM returns no tool calls OR max_iterations reached
  • Consistent with all other agents in utilities, trace logging, and API patterns
